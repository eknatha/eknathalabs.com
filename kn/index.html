ಪ್ರಯೋಗಶಾಲೆ ಎಲ್ಲರಿಗೂ ಉಚಿತ

ತಂತ್ರಜ್ಞಾನ, ಎಲ್ಲರಿಗೂ ಮುಕ್ತ.

ಎಲ್ಲಾ ರೀತಿಯ ತಂತ್ರಜ್ಞಾನಕ್ಕಾಗಿ ಉಚಿತ ಟೂಲ್‌ಗಳು, ಲ್ಯಾಬ್‌ಗಳು ಮತ್ತು ಕಲಿಕೆ, ಇದರಿಂದ ಯಾರಾದರೂ ಕಲಿಯಬಹುದು, ನಿರ್ಮಿಸಬಹುದು ಮತ್ತು ಕೆಲಸ ಮುಗಿಸಬಹುದು.

ನಾಲ್ಕು ಲೈನ್‌ಗಳಲ್ಲಿ 9 ಟೂಲ್‌ಗಳು. ಖಾತೆ ಇಲ್ಲ, ಪಾವತಿ ಇಲ್ಲ. ಒಂದನ್ನು ತೆರೆದು ಪ್ರಾರಂಭಿಸಿ.

ಕಲಿಕೆಯ ಲೈನ್

3 ನಿಲ್ದಾಣಗಳು

ಪ್ರಾಯೋಗಿಕ ಲ್ಯಾಬ್‌ಗಳು ಮತ್ತು ಮಾರ್ಗದರ್ಶಿಗಳು, ನಿಮ್ಮದೇ ವೇಗದಲ್ಲಿ.

  • ವಿಶೇಷ · ಇಲ್ಲಿಂದ ಪ್ರಾರಂಭಿಸಿMARGA ಮಾರ್ಗಕ್ರಮಬದ್ಧ ಕಲಿಕೆಯ ಹಾದಿಗಳು. "ಮಾರ್ಗ" ಎಂದರೆ ದಾರಿ: ಕ್ಲೌಡ್, DevOps ಮತ್ತು SRE ಗಾಗಿ ಆಯ್ದ ರೋಡ್‌ಮ್ಯಾಪ್‌ಗಳು, ಮೊದಲ ಹೆಜ್ಜೆಯಿಂದ ಉದ್ಯೋಗಕ್ಕೆ ಸಿದ್ಧ ಕೌಶಲ್ಯಗಳವರೆಗೆ. marga.eknathalabs.com
  • Linux for DevOps25 ಪ್ರಾಯೋಗಿಕ ಅಭ್ಯಾಸ ಲ್ಯಾಬ್‌ಗಳು, LFCS ಶೈಲಿಯ ರಸಪ್ರಶ್ನೆ ಪ್ರಶ್ನೆಗಳು ಮತ್ತು ಇನ್‌ಲೈನ್ ಟ್ಯುಟೋರಿಯಲ್‌ಗಳು. linux.eknathalabs.com
  • Certifications HubCKA, CKS, AWS, Azure ಮತ್ತು Terraform ಗಾಗಿ ರೋಡ್‌ಮ್ಯಾಪ್‌ಗಳು, ಪರೀಕ್ಷೆಯ ಉದ್ದೇಶಗಳು ಮತ್ತು ಅಧ್ಯಯನ ಯೋಜನೆಗಳೊಂದಿಗೆ. certs.eknathalabs.com

ಕರಿಯರ್ ಲೈನ್

2 ನಿಲ್ದಾಣಗಳು

ಮುಂದಿನ ಹುದ್ದೆಗೆ ಸಿದ್ಧರಾಗಿ.

  • ResumelyticsATS ರೆಸ್ಯೂಮೆ ವಿಶ್ಲೇಷಕ: ಕೀವರ್ಡ್ ವಿಶ್ಲೇಷಣೆ, ಫಾರ್ಮ್ಯಾಟ್ ಸ್ಕೋರಿಂಗ್ ಮತ್ತು ಗುರಿ ಆಧಾರಿತ ಸುಧಾರಣೆಗಳು. resumelytics.eknathalabs.com
  • InterviewHubKubernetes, Terraform, Linux, CI/CD ಮತ್ತು ಕ್ಲೌಡ್‌ನಲ್ಲಿ ಆಳವಾದ ಮಾರ್ಗದರ್ಶಿಗಳು, ಸಂದರ್ಶನ ಮತ್ತು ಫ್ಲ್ಯಾಶ್‌ಕಾರ್ಡ್ ಮೋಡ್‌ಗಳೊಂದಿಗೆ. interviewhub.eknathalabs.com

ಉಲ್ಲೇಖ ಲೈನ್

2 ನಿಲ್ದಾಣಗಳು

ವಿಷಯಗಳನ್ನು ಸರಳ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಿ.

  • Linux Command Explainerಸುಮಾರು 200 ಕಮಾಂಡ್‌ಗಳು ಸರಳ ಭಾಷೆಯಲ್ಲಿ, ಪೈಪ್-ಚೈನ್ ವಿಷುಯಲೈಸರ್, ರೆಜೆಕ್ಸ್ ಡಿಕೋಡರ್ ಮತ್ತು ರನ್ ಮಾಡುವ ಮೊದಲಿನ ಎಚ್ಚರಿಕೆ ಪಟ್ಟಿಯೊಂದಿಗೆ. linux-command-explainer.eknathalabs.com
  • Database EncyclopediaSQL, NoSQL, ಇಂಡೆಕ್ಸಿಂಗ್, ಟ್ರಾನ್ಸಾಕ್ಷನ್‌ಗಳು ಮತ್ತು ಸ್ಕೇಲಿಂಗ್‌ನ 16 ವಿಭಾಗಗಳು, ಸಂವಾದಾತ್ಮಕ ಟೂಲ್‌ಗಳು ಮತ್ತು ರಸಪ್ರಶ್ನೆಗಳೊಂದಿಗೆ. db.eknathalabs.com

ಫೈಲ್ ಲೈನ್

2 ನಿಲ್ದಾಣಗಳು

ವಿನ್ಯಾಸದಿಂದಲೇ ಖಾಸಗಿ. ಎಲ್ಲವೂ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲೇ ನಡೆಯುತ್ತದೆ.

  • PatramPDF ಗಳನ್ನು ವಿಲೀನಗೊಳಿಸಿ, ವಿಭಜಿಸಿ, ಸಂಕುಚಿಸಿ, ಪರಿವರ್ತಿಸಿ ಮತ್ತು ಕ್ರಮ ಬದಲಿಸಿ. ಏನನ್ನೂ ಅಪ್‌ಲೋಡ್ ಮಾಡಲಾಗುವುದಿಲ್ಲ. patram.eknathalabs.comಆಫ್‌ಲೈನ್‌ನಲ್ಲೂ ಕೆಲಸ ಮಾಡುತ್ತದೆ
  • Bimbaಚಿತ್ರಗಳ ಗಾತ್ರ ಬದಲಿಸಿ, ಸಂಕುಚಿಸಿ, ಪರಿವರ್ತಿಸಿ, ಕ್ರಾಪ್ ಮಾಡಿ ಮತ್ತು ಎಡಿಟ್ ಮಾಡಿ. ಅಪ್‌ಲೋಡ್ ಇಲ್ಲ. bimba.eknathalabs.comಆಫ್‌ಲೈನ್‌ನಲ್ಲೂ ಕೆಲಸ ಮಾಡುತ್ತದೆ
ಏಕೆ ಉಚಿತ

ಉತ್ತಮ ತಂತ್ರಜ್ಞಾನಕ್ಕೆ ಪ್ರವೇಶ ಶುಲ್ಕ ಇರಬಾರದು.

ನಮ್ಮ ಗುರಿ ಸರಳ: ಉತ್ತಮ ತಂತ್ರಜ್ಞಾನವನ್ನು ಎಲ್ಲರಿಗೂ ಉಚಿತ ಮತ್ತು ಸುಲಭವಾಗಿ ಲಭ್ಯವಾಗಿಸುವುದು.

01

ಖಾತೆ ಬೇಕಿಲ್ಲ

ಟೂಲ್ ತೆರೆದು ಬಳಸಿ. ಸೈನ್-ಅಪ್ ಇಲ್ಲ, ಕಾರ್ಡ್ ಇಲ್ಲ, ಟ್ರಯಲ್ ಗಡಿಯಾರವಿಲ್ಲ.

02

ನಿಮ್ಮ ಡೇಟಾ ನಿಮ್ಮದೇ

Patram ಮತ್ತು Bimba ಸಂಪೂರ್ಣವಾಗಿ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲೇ ನಡೆಯುತ್ತವೆ. ನಿಮ್ಮ ಫೈಲ್‌ಗಳು ನಿಮ್ಮ ಸಾಧನ ಬಿಟ್ಟು ಹೋಗುವುದಿಲ್ಲ.

03

ಎಲ್ಲರ ಮುಂದೆಯೇ ನಿರ್ಮಾಣ

ಹೊಸ ಟೂಲ್‌ಗಳು ಸಿದ್ಧವಾದಂತೆ ಬರುತ್ತವೆ, ಮುಂದೆ ಏನು ಬರಬೇಕು ಎಂದು ನಿರ್ಧರಿಸಲು ಸಂದರ್ಶಕರು ಸಹಾಯ ಮಾಡುತ್ತಾರೆ.

ವರ್ಕ್‌ಶಾಪ್

ನಾವು ಮುಂದೆ ನಿರ್ಮಿಸುತ್ತಿರುವುದು.

ತೆರೆದ ಡ್ರಾಯರ್‌ಗಳು ನಡೆಯುತ್ತಿರುವ ಕೆಲಸವನ್ನು ತೋರಿಸುತ್ತವೆ. ಪ್ರತಿ ಡ್ರಾಯರ್ ಆರಂಭವಾದ ದಿನವೇ ಲಿಂಕ್ ಆಗುತ್ತದೆ.

ಡ್ರಾಯರ್ 01ನಿರ್ಮಾಣದಲ್ಲಿದೆ

Kubernetes ಲ್ಯಾಬ್

ನಿಜವಾದ ಕ್ಲಸ್ಟರ್ ಸನ್ನಿವೇಶಗಳು, RBAC ಮತ್ತು ನೆಟ್‌ವರ್ಕ್ ಪಾಲಿಸಿಗಳು, CKA ಮತ್ತು CKS ಗೆ ಹೊಂದಿಕೆಯಾಗುವಂತೆ.

ಡ್ರಾಯರ್ 02ನಿರ್ಮಾಣದಲ್ಲಿದೆ

Docker ಲ್ಯಾಬ್

ಮೂಲ ತತ್ವಗಳಿಂದ ಪ್ರೊಡಕ್ಷನ್‌ವರೆಗೆ ಕಂಟೈನರ್‌ಗಳು: Compose, ನೆಟ್‌ವರ್ಕಿಂಗ್, ವಾಲ್ಯೂಮ್‌ಗಳು, ಮಲ್ಟಿ-ಸ್ಟೇಜ್ ಬಿಲ್ಡ್‌ಗಳು ಮತ್ತು ಹಾರ್ಡನಿಂಗ್.

ಡ್ರಾಯರ್ 03ನಿರ್ಮಾಣದಲ್ಲಿದೆ

Terraform ಲ್ಯಾಬ್

AWS, Azure ಮತ್ತು GCP ಯಲ್ಲಿ ಮಲ್ಟಿ-ಕ್ಲೌಡ್ IaC, ಮರುಬಳಕೆಯ ಮಾಡ್ಯೂಲ್‌ಗಳು ಮತ್ತು ಸ್ಟೇಟ್‌ನೊಂದಿಗೆ.

ಡ್ರಾಯರ್ 04ನಿರ್ಮಾಣದಲ್ಲಿದೆ

CI/CD ಲ್ಯಾಬ್

ಪೈಪ್‌ಲೈನ್‌ಗಳು, ArgoCD ಮತ್ತು GitOps, ಶೂನ್ಯದಿಂದ ಪ್ರೊಡಕ್ಷನ್ ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್‌ವರೆಗೆ.

ಡ್ರಾಯರ್ 05ನಿರ್ಮಾಣದಲ್ಲಿದೆ

ArchLab

AWS, Azure, GCP ಮತ್ತು Kubernetes ಆರ್ಕಿಟೆಕ್ಚರ್ ಡೈಗ್ರಾಮ್‌ಗಳು, AI ಸಹಾಯದಿಂದ ಅಥವಾ ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ, 20+ ಟೆಂಪ್ಲೇಟ್‌ಗಳೊಂದಿಗೆ.

ಡ್ರಾಯರ್ 06ಯೋಜನೆಯಲ್ಲಿದೆ

ಕೇಯಾಸ್ ಲ್ಯಾಬ್

ಚಾಲನೆಯಲ್ಲಿರುವ ಕ್ಲಸ್ಟರ್‌ಗಳಲ್ಲಿ ವೈಫಲ್ಯಗಳನ್ನು ತುಂಬಿ, ವಸ್ತುಗಳನ್ನು ಮುರಿದು ಸ್ಥಿತಿಸ್ಥಾಪಕತ್ವ ಕಲಿಯಿರಿ.

ಡ್ರಾಯರ್ 07ಯೋಜನೆಯಲ್ಲಿದೆ

ಟ್ರಬಲ್‌ಶೂಟಿಂಗ್ ಲ್ಯಾಬ್‌ಗಳು

ತಾತ್ಕಾಲಿಕ Linux ಮತ್ತು Kubernetes ಯಂತ್ರಗಳಲ್ಲಿ ಶ್ರೇಣೀಕೃತ ಬ್ರೇಕ್-ಫಿಕ್ಸ್ ಸನ್ನಿವೇಶಗಳು.

ಡ್ರಾಯರ್ 08ಯೋಜನೆಯಲ್ಲಿದೆ

ಕ್ಲೌಡ್ ಆಪರೇಷನ್ಸ್ ಟ್ರ್ಯಾಕ್

AWS ಮತ್ತು Azure ಕಾರ್ಯಾಚರಣೆ: ಘಟನೆಗಳು, ವೆಚ್ಚ, ಸ್ಕೇಲಿಂಗ್ ಮತ್ತು ಭದ್ರತೆ.

ಡ್ರಾಯರ್ 09ಯೋಜನೆಯಲ್ಲಿದೆ

ಸಿಸ್ಟಮ್ ಡಿಸೈನ್ ಪ್ಲೇಗ್ರೌಂಡ್

ಸಿಸ್ಟಮ್‌ಗಳನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸಿ ವೈಫಲ್ಯದ ವಿಧಾನಗಳನ್ನು ಪರೀಕ್ಷಿಸಲು ಸಂವಾದಾತ್ಮಕ ಕ್ಯಾನ್ವಾಸ್.

ಡ್ರಾಯರ್ 10ಯೋಜನೆಯಲ್ಲಿದೆ

ಸೆಕ್ಯುರಿಟಿ ಟ್ರ್ಯಾಕ್

ಪ್ರಾಯೋಗಿಕ ಭದ್ರತಾ ಕಲಿಕೆಗಾಗಿ ಮೀಸಲಾದ ವೇದಿಕೆ.

ಉತ್ತಮ ಟೂಲ್ ಪೇವಾಲ್ ಹಿಂದೆ ಸಿಲುಕಿದೆಯೇ?

ನಿಮಗೆ ಏನು ಬೇಕು ಎಂದು ಹೇಳಿ. ಅದಕ್ಕೆ ಉಚಿತ ಪರ್ಯಾಯದ ಮೇಲೆ ನಾವು ಕೆಲಸ ಮಾಡಿ ನಕ್ಷೆಗೆ ಸೇರಿಸುತ್ತೇವೆ.
